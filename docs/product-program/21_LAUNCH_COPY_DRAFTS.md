## Capture storyboard

1. Real non-sensitive question in the mobile composer.
2. Explicit constraints/priorities, if working in the selected candidate.
3. Genuine result or clearly labeled illustrative sample; no fake elapsed research timer.
4. Open one source and show how it supports the displayed claim.
5. Adjust a supported priority and explain the tradeoff without fake confidence probabilities.
6. Record an actual choice with rationale, if available.
7. Show desktop evidence inspection and return to mobile only if this is actual product behavior.

Keep each sequence legible without sound. Provide captions and alt text. No unsupported comparative claims, fake testimonials, competitor logos implying endorsement, fabricated waitlist counts or unverified performance statistics.
